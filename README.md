🚀 Career Portal - Full Stack Web Application



📌 Overview

A modern Full Stack Career Portal where:

👨‍💼 Candidates can search & apply for jobs

🏢 Companies can post & manage job listings

Built using React + Spring Boot + MySQL



🌐 Live Demo

🚀 Frontend: (https://careerr-portal.netlify.app/)



🛠️ Tech Stack
🎨 Frontend

React.js

Bootstrap / CSS

JavaScript

⚙️ Backend

Spring Boot

Hibernate / JPA

REST APIs

🗄️ Database

MySQL



✨ Features
👨‍💼 Candidate Panel

Register & Login

Search Jobs

Apply for Jobs

Track Applications



🏢 Company Panel

Register & Login

Post Jobs

Manage Job Listings

View Applicants

⚙️ Installation & Setup
🔹 Clone the Repository
git clone https://github.com/Saurabh-1435/career-portal.git

🔹 Backend Setup

cd backend
mvn spring-boot:run

🔹 Frontend Setup

cd frontend

npm install

npm start

🔐 Environment Variables

Create .env file if needed for API URLs.
